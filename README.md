# Investigación: Acceso Móvil a Moodle ULEAM (Fase 3)

Este repositorio contiene la evidencia empírica y los artefactos de diseño del proyecto de investigación sobre el acceso móvil al aula virtual de la ULEAM (Extensión El Carmen).

## Contenido
- `Encuesta_ Acceso móvil a Moodle - ULEAM (Respuestas).xlsx`: Matriz de datos crudos recolectados entre el 4 y 8 de noviembre de 2026 (27 respuestas).
- Artefactos de diseño: Modelo C4 (Contenedores) y Registros de Decisión Arquitectónica (ADRs).
